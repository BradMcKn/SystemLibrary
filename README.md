# SystemLibrary
System Library is a simple library system in Python please enjoy!
Project Overview

This project is a library system written in Python. The system manages information about books and users, allowing users to interact with a book catalog. Users can create book entries, search for books, check out available books, and return them as needed.

Objective

The objective of this library system is to provide a functional and user-friendly interface where users can:

Create new users with a username and user ID.

Add new books to the catalog by entering the title, author, and ISBN.

Search the book catalog to find available books.

Check out and return books.

Application Workflow

User Creation

Prompt the user to create a new user by entering a username and user ID.

Adding a Book

Allow the user to create a book entry by providing the title, author, and ISBN.

Searching the Catalog

Allow the user to search the book catalog for a specific book.

Display whether the book is available or not.

Checking Out a Book

Ask the user if they would like to check the book out.

If yes, verify the book has been checked out.

Remove the book from the available list.

Returning a Book

Ask the user if they would like to return the book.

Verify if the book has been returned successfully.

Checking Current Checkouts

Allow the user to verify if they have any books currently checked out.

If applicable, return the book.

Continuing or Exiting

Ask the user if they would like to perform another action:

If yes, allow the user to add another book.

If no, exit the program and display a goodbye message.

How to Use

When running the application, you will be provided with several options (1 - 9):

Add a book - Enter the title, author, and ISBN.

Search for a book - Search by author or title.

Check out a book - Provide the title of the book you want to check out.

Return a book - Return a previously checked-out book.

View checked-out books - See all books currently checked out by the user.

Create a new user - Enter a name and user ID (required for checking out or returning books).

View all users - Display a list of all users.

Remove a user - Delete a user from the system.

Quit - Exit the program.
